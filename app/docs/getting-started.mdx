# Введение

Reline — библиотека для работы с изображениями, написанная на Python и Rust. Работа с ней происходит при помощи JSON-конфигов, которые представляют собой алгоритм из узлов с набором определённых действий. Каждый узел берёт результат обработки предыдущего и&nbsp;подготавливает данные для&nbsp;следующего шага.

## Интерфейс приложения

<DocImage src="/docs/main.webp" alt="main screen" caption="Интерфейс ПК-версии" />
* **Сверху** доступны опции для кастомизации: смена языка и темы.
* **В левой части (карточка «Узлы»)** находится визуальный редактор, в&nbsp;котором можно добавить, задать порядок и&nbsp;редактировать содержимое узлов.
* **В правой части (карточка «Код»)** отображается созданный конфиг в&nbsp;виде JSON-кода. В выпадающем меню можно выбрать один из готовых пресетов, а также присутствуют кнопки для импорта и экспорта конфигов.
* **Снизу** идут ссылки на&nbsp;ресурсы, где&nbsp;данным конфигом можно воспользоваться.

## Базовая схема

1. <NodeRef type="folder_reader" /> — чтение исходных изображений из&nbsp;папки.
2. Вся остальная логика.
3. <NodeRef type="folder_writer" /> — сохранение результата в&nbsp;выбранную папку.

## Краткое описание функционала обрабатывающих узлов

* <NodeRef type="upscale" /> — обрабатывает изображение при&nbsp;помощи моделей на&nbsp;базе машинного&nbsp;обучения;
* <NodeRef type="sharp" /> — используется для коррекции линий после DS-моделей<br/>(подробнее в <ArticleRef slug="rescreentone" />);
* <NodeRef type="screentone" /> — перенакладывает скринтон при&nbsp;помощи детерминированного алгоритма;
* <NodeRef type="level" /> — смещение света и&nbsp;теней, аналог уровней в&nbsp;Photoshop;
* <NodeRef type="cvt_color" /> — конвертация в&nbsp;определённое цветовое пространство.
