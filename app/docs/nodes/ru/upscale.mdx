# Upscale

`Upscale` увеличивает разрешение изображения с помощью выбранной модели.

## За что отвечает нода

- выбор модели;
- точность вычислений или `dtype`;
- стратегия тайлинга;
- точный размер плитки;
- разрешение на CPU fallback.
- Более крупные плитки могут дать лучший результат, но потребляют больше видеопамяти.
